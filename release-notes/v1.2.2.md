### What's new
- **Reproducible builds.** The app now builds byte-for-byte identically on any machine. F-Droid can verify that its build matches this one and ship it with the same signature, so you can move between the GitHub and F-Droid versions without uninstalling.
- **Two APKs in this release:**
  - `material-island-1.2.2.apk` is the usual version. It can update itself from GitHub if you allow it.
  - `material-island-1.2.2-fdroid.apk` is the same app without the updater, the build F-Droid uses. Pick it only if you'll get updates from F-Droid or Obtainium.

Updating: open Material Island and tap **Update** on the card (or **About → Check for updates**), or install the APK over the old one. Your settings are kept.
