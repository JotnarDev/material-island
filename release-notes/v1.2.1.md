### What's new
- **You choose whether to check for updates.** The first time you open the app, it asks whether it should check GitHub for new versions. Until you answer, it doesn't contact GitHub. You can change this later in **About**.
- **New release key.** Releases are now signed with a dedicated release key instead of a development key. The new key is linked to the old one, so **existing installs update normally**, without uninstalling.
- **Releases are built automatically** by GitHub Actions, straight from the tagged source code.
- **Getting ready for F-Droid:** the app now has a store listing (descriptions, icon and screenshots in English and Spanish) and a separate F-Droid build without the updater.

Updating from 1.1.1 or later: open Material Island and tap **Update** on the card (or **About → Check for updates**). From older versions, install this APK over the old one. Your settings are kept.
